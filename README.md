# سهم، ساخت اولیهٔ ویندوز
پروژهٔ Flutter برای ویندوز ۱۱ نسخهٔ ۶۴ بیتی. خرید، فروش، ویرایش، نرخ دستی و بهای میانگین در این ساخت پیاده شده‌اند. این بسته سورس است. هنوز روی ویندوز کامپایل و تأیید نشده است.
برای ساخت روی رایانهٔ توسعه، Flutter پایدار و Visual Studio با مؤلفهٔ Desktop development with C++ نصب شوند. در پوشهٔ پروژه در PowerShell دستور زیر را اجرا کنید.
```powershell
.\build-windows.ps1
```
اسکریپت پروژهٔ ویندوز را ایجاد می‌کند، وابستگی‌ها را می‌گیرد، تست‌ها را اجرا می‌کند و نسخهٔ Release می‌سازد. پوشهٔ Release باید کامل کنار فایل اجرایی باشد. در صورت وجود Inno Setup و دسترسی به ISCC.exe از PATH، فایل Output/Sahm-Setup.exe هم تولید می‌شود. این نسخه هنوز برای نگهداری تنها نسخهٔ اطلاعات مالی مناسب نیست. فایل SQLite فعلاً رمزگذاری نشده است.
